# PolicyLens — AI-Driven Privacy Policy Analyzer

## About the Project
Privacy policies are often excessively long, filled with legal jargon, and difficult for the average user to understand. As a result, users frequently agree to terms they haven't read or fully comprehended, unknowingly compromising their privacy.

**Problem it solves:** This project tackles this issue by providing an AI-powered platform that summarizes complex privacy policy documents into easily readable key points. It also includes an interactive question-answering system, allowing users to ask specific questions about the policy (e.g., "Do they sell my data?") and receive clear answers directly extracted from the document. 

## Features
- **User Authentication:** Secure signup and login system to save user preferences and access the dashboard.
- **Text Summarization:** Upload a PDF or paste raw text to receive a concise, simplified summary generated by the `facebook/bart-large-cnn` model.
- **Contextual Q&A:** Ask specific questions about the policy and get direct answers extracted by the `distilbert-base-uncased-distilled-squad` model.
- **Direct PDF Support:** Upload official PDF documents directly for quick processing without manual text extraction.
- **Modern Dashboard:** A clean, responsive, light-themed user interface built with Bootstrap 5.

## Tech Stack Used

### Frameworks & Libraries
- **Flask (Python):** Primary backend web framework.
- **Flask-SQLAlchemy & Flask-Login:** For robust database management and secure user authentication.
- **Hugging Face `transformers`:** State-of-the-art NLP library used to execute pre-trained AI models.
- **PyTorch (`torch`):** Deep learning framework running the NLP models.
- **PyMuPDF (`fitz`):** High-performance PDF processing library for text extraction.

### Algorithms & Models
- **BART (`facebook/bart-large-cnn`):** Sequence-to-sequence transformer model for abstractive summarization.
- **DistilBERT (`distilbert-base-uncased-distilled-squad`):** Distilled BERT model fine-tuned on SQuAD for highly accurate question answering.

### Frontend
- **HTML / CSS / Bootstrap 5 & Jinja2:** Modern responsive UI dynamically rendered from the Flask backend.

## Prerequisites
- **Python 3.11** installed on your system.
- Git installed on your system.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/jenilia2786/Privacy-Policy-Simplifier.git
   cd Privacy-Policy-Simplifier
   ```

2. Create and activate a virtual environment:
   ```powershell
   py -3.11 -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Install the required dependencies:
   ```powershell
   pip install --default-timeout=1000 -r requirements.txt
   ```

4. Run the Flask application:
   ```powershell
   python app.py
   ```
   *(Alternatively, on Windows, you can simply double-click the `run_all.bat` script!)*

5. Open your web browser and navigate to `http://127.0.0.1:5000`.
