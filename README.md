# Privacy Policy Simplifier

## About the Project
Privacy policies are often excessively long, filled with legal jargon, and difficult for the average user to understand. As a result, users frequently agree to terms they haven't read or fully comprehended, unknowingly compromising their privacy.

**Problem it solves:** This project tackles this issue by providing an AI-powered tool that summarizes complex privacy policy documents into easily readable key points. It also includes an interactive question-answering system, allowing users to ask specific questions about the policy (e.g., "Do they sell my data?") and receive clear answers directly extracted from the document. 

## Features
- **Text Summarization:** Upload a PDF or paste raw text to receive a concise, simplified summary generated by the `facebook/bart-large-cnn` model.
- **Question Answering:** Ask specific questions about the policy and get direct answers extracted by the `distilbert-base-uncased-distilled-squad` model.
- **Direct PDF Support:** Upload official PDF documents directly for quick processing without manual text extraction.

## Tech Stack Used
- **Backend:** Flask (Python)
- **AI / NLP Models:** Hugging Face `transformers` library (BART for summarization, DistilBERT for QA)
- **PDF Processing:** `PyMuPDF` (fitz)
- **Frontend:** HTML/CSS (Jinja2 Templates)

## Prerequisites
- Python 3.7+ installed on your system.
- Git installed on your system.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/jenilia2786/Privacy-Policy-Simplifier.git
   cd Privacy-Policy-Simplifier
   ```

2. Create and activate a virtual environment (recommended):
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Install the required dependencies:
   ```bash
   pip install flask transformers PyMuPDF torch
   ```

4. Run the Flask application:
   ```bash
   python app.py
   ```

5. Open your web browser and navigate to `http://127.0.0.1:5000`.
